# FIN-016: Financial Audit Log Export — As-Built Gaps

- [HIGH] No PDF export format — `app/routers/audit_export.py:78` only accepts `format` values `"csv"` or `"ndjson"`; `audit_export_pipeline.py` never calls a PDF renderer — FIN-016 requires audit-grade PDF with cover page, sequential row numbers, page subtotals, and SHA-256 footer; currently impossible. Fix: add `"pdf"` to allowed formats, implement `_render_pdf(rows, ...)` in `audit_export_pipeline.py` using `reportlab` or `weasyprint`. Effort: L

- [HIGH] No scheduled report system — neither `audit_export_pipeline.py` nor `audit_export.py` router contain a `SCHEDULE#*` row pattern or background task for recurring exports — FIN-016 requires daily/weekly/monthly auto-exports emailed to recipients. Fix: add `SCHEDULE#{id}` rows to `AuditExports` table with `next_run_at` GSI SK, a `run_scheduled_exports()` background task registered in `app/main.py`, and CRUD endpoints for schedule management. Effort: L

- [HIGH] No accounting-software column mapping — `audit_export.py` `CSV_COLUMNS` at `audit_export_pipeline.py:22` are generic audit columns (event_id, actor_user_id, etc.), not QuickBooks or Xero financial columns — Finance teams cannot auto-import exports. Fix: add `column_format` param to export request; map billing ledger fields to QuickBooks (`Date`, `Transaction Type`, `Amount`, `Name`, …) and Xero formats when `format=csv` and `category=billing`. Effort: M

- [MED] Billing-specific filters (amount range, entry_type, per-user ledger) not exposed — `app/routers/audit_export.py:64` accepts `categories`, `format`, `from_ts`, `to_ts`, `actor_user_id`, `target_user_id` but not `amount_min`, `amount_max`, `entry_type` — Admins cannot filter the billing export to only tip debits or amounts above $X. Fix: add optional `amount_min_cents`, `amount_max_cents`, `entry_types` fields to the request body and apply them as FilterExpression in `BillingLedgerAdapter.query` (`audit_adapters.py:354`). Effort: M

- [MED] `AuditExportPage.tsx` shows only categories/format/date-range controls — `frontend/src/pages/admin/AuditExportPage.tsx:36` has no per-user filter, no amount filters, no accounting-format selector, and no schedule management tab — Discovered gaps 3 and 4 have no frontend surface. Fix: extend AuditExportPage with billing-specific filter section and Schedules tab. Effort: M

- [LOW] `BillingLedgerAdapter` uses a full-table scan with FilterExpression — `app/services/audit_adapters.py:394` calls `self._paginate_scan(T.billing, FilterExpression=filter_expr)` rather than querying by user PK — Large tables make this extremely slow. Fix: when `actor_user_id` is set, query `T.billing` via PK=`USER#{actor_user_id}` + SK prefix `LEDGER#` instead of scanning. Effort: M
