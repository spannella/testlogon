# MSG-001 gaps — Message Editing & Deletion

- [HIGH] no time-window enforcement on edit — `app/routers/messaging.py:11003` — `edit_message()` has no check against `MESSAGE_EDIT_WINDOW_SECONDS`; senders can edit indefinitely long after recipients have read and acted on the original content — Fix: add `if now_ts() - int(msg.get("created_at",0)) > S.message_edit_window_seconds: raise HTTPException(400, ...)` and add `message_edit_window_seconds: int` to `app/core/settings.py` — Effort: S

- [HIGH] platform-level admin/root cannot delete any message — `app/routers/messaging.py:10762,10801` — `delete_message_for_me` only soft-hides for the calling user; `revoke_message_for_all` requires conversation-level "admin" participant role, not the platform ADMIN/ROOT role — Fix: check `ctx["role"] in {Role.ADMIN, Role.ROOT}` in `revoke_message_for_all` (or add a separate moderation endpoint) to allow platform admins to remove harmful content — Effort: M

- [MED] frontend "Delete" action calls DELETE (delete-for-me), not DELETE /revoke — `frontend/src/api/endpoints/messaging.ts:459` — UI "Delete" button only hides the message from the sender's own view; the recipient still sees the full content — Fix: change `deleteMessage` to call `/revoke` (delete-for-all) with a confirmation dialog noting "Delete for everyone"; keep the current endpoint as "Hide from my view only" — Effort: M

- [MED] no `MESSAGE_EDIT_DELETE_ENABLED` feature flag — `app/core/settings.py` — edit and delete endpoints are always enabled; cannot disable without code changes — Fix: add `message_edit_delete_enabled: bool` to `Settings` and check it in both endpoints — Effort: S

- [LOW] edit history SK (`edited_at`) stored as string not number — `app/routers/messaging.py:11044` — `str(ts)` written as DDB string, but `MessageEdits` table at `scripts/local-ddb-init.py:276` sorts lexicographically; multiple edits within the same second will have undefined ordering — Fix: store `edited_at` as integer and declare `attr_types={"edited_at": "N"}` in TableDef — Effort: S

- [LOW] frontend "edited" indicator shows raw `<span>edited</span>` with no timestamp tooltip — `frontend/src/pages/messages/MessageBubble.tsx:1937` — no hover tooltip showing when the edit was made, unlike Telegram/Discord UX — Fix: wrap with `<Tooltip>` showing formatted `message.edited_at` timestamp — Effort: S
