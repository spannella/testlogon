# PWA-003 Gaps

- [MED] view-once messages cached in plain IndexedDB — `frontend/src/lib/withOfflineCache.ts:36-68` — view-once ciphertext is cached unfiltered; a user who has not yet consumed a view-once message could read it offline if they know to inspect IDB directly — Fix: strip entries with `view_once: true` from the response before calling `setCachedResponse`; or set `ttlSeconds=0` for pages that contain any view-once message — Effort: S

- [MED] `api_cache_meta.entryCount` overcounts — `frontend/src/lib/offlineCache.ts:612-625` — `entryCount` increments on every `put` including overwrites (same cacheKey), so the meta store inflates; also `totalSizeEstimate` never shrinks on eviction — Fix: use `IDBKeyRange` count against the `endpoint` index for true count; decrement size on evict/delete — Effort: S

- [LOW] Image cache LRU is insertion-order, not access-order — `frontend/public/sw.js:149-154` — oldest-inserted entries are evicted even if recently accessed; images for the active conversation are evicted before images for conversations that were never re-opened — Fix: timestamp entries or use a named-key scheme that is touched on access — Effort: M

- [LOW] Missing E2E spec for expired-cache does-not-serve path (97.3) — `frontend/e2e/pwa-offline-cache.spec.ts` — test 97.3 manipulates IDB to back-date `cachedAt` then goes offline but makes no assertion about what the UI actually shows (no `expect` after reconnect) — Fix: add assertion that the conversations list shows an error/empty state rather than the stale data — Effort: S
