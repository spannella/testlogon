# PWA-001 gaps

- [MED] Apple splash screen images not generated or referenced — `frontend/index.html` (no `<link rel="apple-touch-startup-image">` tags); `frontend/public/splash/` directory does not exist — iOS users who add the app to home screen see a blank white screen during launch instead of a branded splash — Fix: generate splash PNGs via `scripts/generate-pwa-icons.sh` and add `<link rel="apple-touch-startup-image">` tags to `index.html` for the three target device sizes in the ticket spec — Effort: S

- [MED] Screenshots not provided in manifest — `frontend/public/manifest.json` (no `screenshots` field); `frontend/public/screenshots/` directory does not exist — Chrome's enhanced install dialog (shown in Android Chrome 110+) cannot display app screenshots; reduces install conversion — Fix: capture desktop and mobile screenshots per ticket §3.1 and add the `screenshots` array to `manifest.json` — Effort: S

- [LOW] `pwaUtils.ts` utility module not created — `frontend/src/lib/` (file absent) — `isStandaloneMode()` / `getDisplayMode()` helpers are not available for reuse by other components; `InstallPrompt.tsx` duplicates the standalone detection logic inline with `window.matchMedia` — Fix: create `frontend/src/lib/pwaUtils.ts` as specified in ticket §3.9 and import it from `InstallPrompt.tsx` — Effort: S

- [LOW] `IOSInstallHint` component not implemented — `frontend/src/components/shared/InstallPrompt.tsx:14` exports only `InstallPrompt` (via `useInstallPrompt` hook), not `IOSInstallHint`; AppShell imports only `InstallPrompt` — iOS Safari users receive no guidance to use "Share > Add to Home Screen" — Fix: implement `IOSInstallHint` component as specified in ticket §3.5 and render it in `AppShell` after `<InstallPrompt />` — Effort: S

- [LOW] Vite build-time `CACHE_VERSION` injection plugin not implemented — `frontend/vite-plugin-sw-version.ts` (file absent); `frontend/vite.config.ts` has no `swVersionPlugin()` — Deployments require a manual bump of `CACHE_VERSION` in `sw.js`; automated CI builds will serve stale cached assets unless developers remember — Fix: create the plugin per ticket §3.7 and add it to `vite.config.ts`; mark as optional (deferred to PWA-002 is acceptable) — Effort: S
