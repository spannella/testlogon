# MSG-002 gaps — Voice Messages

- [HIGH] presign endpoint does not validate that `s3_key` submitted to create endpoint matches the presigned key — `app/routers/messaging.py:8362` — a user could presign for one `s3_key` then submit `create_voice_message` with an arbitrary `s3_key` pointing to another user's file or a non-existent object; no ownership check prevents this — Fix: store the presigned `(message_id → s3_key)` mapping in DDB or a short-TTL cache and verify it matches in `create_voice_message` — Effort: M

- [MED] `content_type` not re-validated in `create_voice_message` — `app/routers/messaging.py:8362` — only the presign endpoint validates `content_type` against `^audio/(webm|mp4|ogg|wav)`; the create endpoint accepts whatever `content_type` is submitted, allowing unexpected MIME types to be stored — Fix: add the same regex validator to `CreateVoiceMessageRequest.content_type` — Effort: S

- [MED] `waveform_data` list items not clamped/validated as floats in `CreateVoiceMessageRequest` — `app/routers/messaging.py:8399` — clamping happens post-validation in endpoint logic, but out-of-range or non-numeric values (e.g. `null` JSON items) can pass Pydantic validation and cause `float()` errors — Fix: add a `@validator("waveform_data")` that runs `[max(0.0, min(1.0, float(v))) for v in ...]` at model level — Effort: S

- [LOW] no `VOICE_MESSAGE_ENABLED` guard on `presign_voicemail` endpoint — `app/routers/messaging.py:8518` — the voicemail presign path lacks the `if not S.voice_message_enabled` guard present in the voice message path (`app/routers/messaging.py:8338`), so voicemail uploads proceed even when the feature is flagged off — Fix: add `if not S.voice_message_enabled: raise HTTPException(404)` to `presign_voicemail` — Effort: S

- [LOW] no E2E test file for voice messages — the ticket notes `frontend/e2e/voice-messages.spec.ts` should exist but it is not present in the test suite — Fix: create the spec file covering presign + create + waveform validation + listen-once + scheduled send (15 tests as designed) — Effort: L
