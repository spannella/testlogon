# FIN-015: Fraud Detection Dashboard — As-Built Gaps

- [HIGH] Billing router never calls fraud evaluation — `app/routers/billing.py` (no call to `fd.evaluate_transaction`), `app/routers/billing_ccbill.py` (same) — Transactions (tips, unlocks, deposits) proceed without velocity/risk checks; the fraud engine exists but is never invoked on the hot payment path. Fix: import `fraud_detection.evaluate_transaction` in billing tip/unlock/deposit handlers and gate on the returned `action`; freeze check via `fd.is_frozen` at `app/services/fraud_detection.py:428`. Effort: M

- [HIGH] Chargeback not auto-recorded from Stripe webhook — `app/routers/billing.py:687` (`billing_config()` is present but no `charge.dispute.created` webhook handler calls `fd.record_chargeback`) — Chargeback threshold rule in `fraud_detection.py:512` is only triggered when admin manually POSTs `/v1/admin/fraud/chargebacks`; live Stripe disputes never increment `chargeback_count`. Fix: add `charge.dispute.created` case in Stripe webhook handler calling `fd.record_chargeback(user_id=..., amount_cents=..., tx_id=...)`. Effort: M

- [MED] `compute_risk_score` ignores `account_age_days` parameter when called from `evaluate_transaction` — `app/services/fraud_detection.py:262` passes `account_age_days` to `evaluate_transaction` but `new_account_check` at `:167` uses it correctly; however `compute_risk_score` at `:196` does not receive account age from the caller, leaving `account_age_score` as 0 permanently — Fix: thread `account_age_days` through `evaluate_transaction` → `compute_risk_score`. Effort: S

- [MED] `get_fraud_stats` frozen-user count is hardcoded to 0 — `app/services/fraud_detection.py:637` comment says "Requires scan — use cached count in production" but returns `"frozen_users": 0` — Dashboard stat is incorrect. Fix: maintain a `COUNTER#FROZEN` atomic counter row in DDB, incremented/decremented by `freeze_user`/`unfreeze_user`. Effort: S

- [LOW] No E2E test spec for fraud dashboard — ticket spec calls for a `frontend/e2e/fraud-detection.spec.ts` file; none exists — Regression risk. Effort: M
