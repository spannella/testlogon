# FIN-018: Billing Configuration UI — As-Built Gaps

- [HIGH] Fee BPS settings are not wired to live billing fee calculations — `app/services/billing_config.py` `get_fee_bps(entry_type)` at `:430` exists but is never imported by `app/routers/billing.py`, `app/services/billing_shared.py`, or any tip/unlock/deposit handler — Runtime fee changes via the UI have zero effect on actual transaction fees; only `get_min_payout_cents()` is consumed (by `creator_payouts.py:176`). Fix: import and call `billing_config.get_fee_bps("tip_debit")` (etc.) in each billing handler that deducts a platform fee instead of using hardcoded constants. Effort: M

- [HIGH] `call_billing_timer.py` reads platform fee from `S.call_billing_platform_fee_percent` (env var) — `app/services/call_billing_timer.py:183` converts the env-var setting to BPS; billing_config `fee_call_bps` (if it exists in the config schema) is ignored — Per-minute call fees cannot be changed at runtime via the config UI. Fix: replace `S.call_billing_platform_fee_percent * 100` with `billing_config.get_fee_bps("call")` (or equivalent). Effort: S

- [MED] `preview_impact` queries the billing ledger with a full-table scan — `app/services/billing_config.py:522` iterates the billing table to compute last-7-day volume; `BillingLedgerAdapter` in `audit_adapters.py:394` also scans — On a production table this is slow and expensive. Fix: use per-user PK queries or a summary rollup table (from FIN-013) for the impact preview calculation. Effort: M

- [LOW] `BillingConfigPage.tsx` does not show impact preview UI — `frontend/src/pages/admin/BillingConfigPage.tsx` (391 lines) has PATCH and audit-log display, but no "Preview Impact" button wired to `POST /ui/admin/billing-config/preview` — Admins cannot see projected revenue delta before committing a fee change. Fix: add a Preview panel in the frontend that calls the existing `/preview` endpoint and displays `projected_daily_delta_cents` + before/after sample. Effort: S

- [LOW] No E2E test spec for billing configuration — ticket spec calls for a `frontend/e2e/billing-config.spec.ts` file; none exists — Regression risk for fee update, preview, reset, and audit log paths. Effort: S
