# MSG-006 gaps — Emoji Messages

- [MED] emoji dataset is imported statically (not lazy-loaded) — `frontend/src/components/shared/EmojiPicker.tsx:16-23` — emoji-data.ts (~430 lines of JSON-like tuples) is bundled synchronously in the main chunk instead of being dynamically imported on first picker open; increases initial load for all pages even when the picker is never opened — Fix: wrap import in `React.lazy` / dynamic `import("@/data/emoji-data")` inside the EmojiPicker or a top-level `useMemo`; trigger load on first `open=true` — Effort: S

- [MED] no arrow-key grid navigation in EmojiPicker — `frontend/src/components/shared/EmojiPicker.tsx:118-123` — only `Escape` key is handled on the picker container; the spec requires full arrow-key navigation (Up/Down/Left/Right + Enter to select) for accessibility; WCAG 2.1.1 requires keyboard operability of all focusable UI — Fix: add `onKeyDown` handler on the grid container tracking focused emoji index with `useRef`, update focus on Arrow keys, fire `handlePick` on Enter — Effort: M

- [LOW] `EMOJI_PICKER_ENABLED` and `EMOJI_LARGE_RENDERING_ENABLED` feature flags absent — `app/core/settings.py` — only `emoji_shortcodes_enabled` exists; the ticket specifies three separate flags so the picker and large-rendering can be toggled independently in prod without a deploy — Fix: add `emoji_picker_enabled` and `emoji_large_rendering_enabled` bool settings; gate the ComposeBar emoji button and the `isEmojiOnly` class in MessageBubble behind them — Effort: S

- [LOW] emoji dataset is a curated subset, not the full ~1800-entry Unicode CLDR dataset — `frontend/src/data/emoji-data.ts:4` — the file comment explicitly notes it is "a representative subset … not the full ~1800-entry Unicode set"; flags, less common symbols, and many skin-tone variants are missing — Fix: replace with the full `unicode-emoji-json` npm package data at build time, or expand the hand-curated set to cover all Unicode 15 categories fully — Effort: M
