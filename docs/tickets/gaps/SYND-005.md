# SYND-005 Gaps — Syndicate Page & Newsfeed

- [MED] Visibility-filtered feed pagination may return an empty page with a non-null next_cursor when all fetched posts are members_only — `app/services/syndicate_feed.py:163-219` — the service fetches `limit*2` items and filters Python-side, but if every fetched item is members_only (e.g., a syndicate posts exclusively members-only content) a non-member receives 0 posts yet a next_cursor is emitted; the frontend must paginate indefinitely to get any public posts — Fix: loop with `LastEvaluatedKey` until `len(visible) >= limit` or DDB is exhausted, similar to the pattern used in `list_conversations` — Effort: M

- [MED] post_count decrement expression can produce a negative value when a post is deleted from a syndicate whose `post_count` attribute has not yet been set — `app/services/syndicate_feed.py:257-264` — the increment uses `if_not_exists(..., :z) + :one` (safe), but the decrement uses `post_count - :one` without a floor guard; if `post_count` is 0 or absent it will underflow to -1 or raise a DynamoDB error — Fix: use `SET post_count = if_not_exists(post_count, :z) - :one` with a `ConditionExpression="post_count > :zero"` or clamp at 0 — Effort: S

- [MED] create_syndicate_post raises a bare `PermissionError` / `ValueError` / `LookupError` instead of `HTTPException` — `app/services/syndicate_feed.py:103-115` — the router must catch these non-HTTP exceptions and translate them; if FastAPI's default exception handler catches them, the client receives a 500 instead of a 403/422/404 — Fix: raise `HTTPException(status_code=403, ...)` / `HTTPException(status_code=422, ...)` / `HTTPException(status_code=404, ...)` directly in the service, matching the pattern used in `syndicates.py` — Effort: S

- [LOW] update_syndicate_profile has no rate-limit enforcement despite the spec requiring max 10 per day — `app/services/syndicate_feed.py:340-396` — an admin can call the update endpoint in a tight loop; no per-syndicate throttle exists — Fix: integrate platform rate-limiter on the `PUT /profile` endpoint — Effort: S
