# GAP-0261: `app/services/kyc_signature_templates.py` does not exist — Remediation Write-up

> ~5 pages. Fix-oriented. Read the real code before writing; cite `file:line`. No investigation
> doc exists for this gap; code verification was performed as part of this write-up.

## 1. Summary & Classification

**Gap**: The service file `app/services/kyc_signature_templates.py`, required by KYC-007
(Enhanced Document Signing), was never created. KYC-007 specifies a template library of
five hard-coded KYC consent/declaration templates (terms_of_service, aml_declaration,
pep_declaration, tax_compliance, data_consent), each with auto-populated fields, version
tracking, and witness co-signing support. None of that business logic exists anywhere in
the codebase.

**Verdict**: Confirmed. `ls app/services/kyc*` shows 22 service files; `kyc_signature_templates.py`
is absent. A grep across the entire `app/` tree for `KYC_TEMPLATE_TYPES`, `create_packets_for_case`,
`auto_populate_fields`, and `check_version_migration` returns zero results.

- **Severity**: HIGH
- **Source ticket**: KYC-007 / GAP-0261
- **Status**: Open
- **Owning area**: KYC / Document Signing
- **Impact**: Users can only attach an ad-hoc, manually prepared PDF to their KYC case for
  consent signing. There is no standardised compliance template workflow. Regulated workflows
  (AML declaration, PEP disclosure, data consent) that require a versioned paper trail are
  silently skipped.
- **Related tickets**: GAP-0262 (router endpoints missing), GAP-0263 (notary_stamp field type),
  GAP-0264 (case data model — single vs list of packets). All four gaps must be resolved
  together; this service is the foundation the router (GAP-0262) and data model (GAP-0264)
  depend on.

## 2. Current-State Investigation (root cause)

### 2.1 What exists

The signature packet infrastructure from KYC-001 is fully operational:

- `app/services/signature_packet_store.py` — `create_draft_packet` (line 91),
  `get_packet` (line 121), `upsert_packet_field` (line 133), `list_packet_signers` (line 175).
- `app/services/signature_packet_domain.py` — `SignatureFieldType` enum (lines 20–27); the
  enum already includes `NOTARY_STAMP` but that is the subject of GAP-0263.
- `app/routers/kyc_cases.py` — `create_or_link_signature_packet()` at line 1285 creates a
  generic packet from a user-uploaded PDF and stores a single `packet_id` in `case["signature"]`.

### 2.2 What is missing

`kyc_signature_templates.py` is the service that should wrap the existing packet-store
primitives into a KYC-specific template workflow. Per the KYC-007 spec
(`docs/tickets/KYC-007-enhanced-document-signing.md`, section 3.1–3.2), the missing
service must expose:

| Symbol | Purpose |
|--------|---------|
| `KYC_TEMPLATE_TYPES` | Dict of five consent-form templates with fields, version, `required_for` tiers |
| `KycSignatureTemplateService.get_required_templates()` | Filter templates by `intake_profile` |
| `KycSignatureTemplateService.create_packets_for_case()` | Create one packet per required template, auto-populate fields from the user's profile |
| `KycSignatureTemplateService.auto_populate_fields()` | Pull `display_name`, `email`, `mailing_address`, etc. from DynamoDB `users` table |
| `KycSignatureTemplateService.get_template_version()` | Return current version string per template type |
| `KycSignatureTemplateService.check_version_migration()` | Detect templates that have been updated since the case was last signed |
| `KycSignatureTemplateService.migrate_template()` | Create a replacement packet from the new template version and mark the old one stale |

The fix spec also mentions `add_witness_signer()` for high-risk cases, which adds an admin
as a second signer with four additional fields (`witness_name`, `witness_role`,
`witness_signature`, `witness_date`). This is co-located in this service.

### 2.3 How the absence manifests at runtime

Because the router endpoints that call this service are also absent (GAP-0262), no HTTP 500
errors surface. The failure is silent and structural: a KYC applicant on a high-risk intake
profile submits their case with a single manually-uploaded consent PDF when the compliance
policy requires five separate signed declarations. The readiness gate (`_readiness_for_case`
at `app/routers/kyc_cases.py:244`) only checks that **a** single packet exists; it has no
concept of template completeness. An admin reviewing the queue sees only `packet_status:
completed` but has no record that AML or PEP declarations were obtained.

## 3. Impact / Exploit / Blast Radius

### 3.1 Compliance / Regulatory

Five KYC consent forms mandated by AML/KYC frameworks are never collected:
- Terms of Service Agreement
- Anti-Money Laundering Declaration
- Politically Exposed Person Declaration
- Tax Compliance Declaration (W-9/W-8BEN equivalent)
- Data Processing Consent

A regulatory audit of case archives will show that only one generic PDF was signed, not the
required declaration set. This constitutes a gap in the risk-based approach (RBA)
documentation required by most jurisdictions.

### 3.2 Data integrity

High-risk and enhanced intake profiles explicitly require PEP and tax compliance declarations
(`required_for: ["enhanced", "high_risk"]`). Cases submitted under these profiles today
pass the signature readiness gate with a single generic packet, meaning the stored evidence
snapshot (`case["submission"]["evidence_snapshot"]["signature"]`) references a packet that
is not the correct compliance document.

### 3.3 Version drift

Without `check_version_migration()`, any change to the template text (e.g., updated
legal notice version tracked by `S.signature_packet_legal_notice_version`) cannot be
propagated to open cases. Users who submitted under an older template version are never
asked to re-sign.

### 3.4 Blast radius

- Every KYC case submitted on `enhanced` or `high_risk` intake profile is potentially
  non-compliant from a documentation standpoint.
- There is no financial or authentication exploit, but the compliance and legal exposure
  for the platform operator is HIGH.

## 4. Fix Design (code-level)

### 4.1 New file: `app/services/kyc_signature_templates.py`

Create the service with the following structure (key signatures shown; full implementation
omitted per scope):

```python
# app/services/kyc_signature_templates.py

from __future__ import annotations
from typing import Any
from app.core.tables import T
from app.core.time import now_ts
from app.services.signature_packet_store import (
    create_draft_packet, upsert_packet_field, add_signer,
)
from app.services.signature_packet_domain import SignatureFieldType
from uuid import uuid4

KYC_TEMPLATE_TYPES: dict[str, dict[str, Any]] = {
    "terms_of_service": {
        "display_name": "Terms of Service Agreement",
        "description": "Platform terms and conditions acceptance",
        "version": "2026-05-v1",
        "required_for": ["standard", "enhanced", "high_risk"],
        "fields": [
            {"id": "full_name",   "type": "text",      "label": "Full Legal Name",
             "auto_populate": "display_name"},
            {"id": "date_of_birth","type": "text",     "label": "Date of Birth",
             "auto_populate": "date_of_birth"},
            {"id": "signature",   "type": "signature", "label": "Signature"},
            {"id": "date_signed", "type": "date",      "label": "Date"},
        ],
    },
    "aml_declaration":  { ... },
    "pep_declaration":  { ... },
    "tax_compliance":   { ... },
    "data_consent":     { ... },
}

# Witness fields appended for high-risk packets
WITNESS_FIELDS = [
    {"id": "witness_name",      "type": "text",      "label": "Witness Name",
     "signer": "witness"},
    {"id": "witness_role",      "type": "text",      "label": "Witness Role",
     "default": "KYC Reviewer", "signer": "witness"},
    {"id": "witness_signature", "type": "signature", "label": "Witness Signature",
     "signer": "witness"},
    {"id": "witness_date",      "type": "date",      "label": "Date",
     "signer": "witness"},
]


class KycSignatureTemplateService:

    def get_required_templates(self, *, intake_profile: str) -> list[dict]:
        """Return template configs required for the given intake_profile."""
        profile = intake_profile.lower()
        return [
            {"template_type": k, **v}
            for k, v in KYC_TEMPLATE_TYPES.items()
            if profile in v["required_for"]
        ]

    def create_packets_for_case(self, *, case_id: str, user_sub: str,
                                 intake_profile: str,
                                 source_pdf_path: str) -> list[dict]:
        """Create one signature packet per required template.
        Auto-populates fields from user profile.
        Returns list of {template_type, packet_id, version}."""
        templates = self.get_required_templates(intake_profile=intake_profile)
        profile = self._load_profile(user_sub)
        results = []
        for tmpl in templates:
            packet = create_draft_packet(
                owner_user_id=user_sub,
                source_path=source_pdf_path,
                source_content_type="application/pdf",
                source_name=tmpl["display_name"],
                origin_channel="kyc_template",
                origin_ref=f"{case_id}:{tmpl['template_type']}",
            )
            packet_id = packet["packet_id"]
            populated = self.auto_populate_fields(
                template=tmpl, profile=profile
            )
            for fdef in tmpl["fields"]:
                upsert_packet_field(
                    packet_id=packet_id,
                    field_id=fdef["id"],
                    page=1,
                    x=0.0, y=0.0, width=200.0, height=30.0,
                    field_type=SignatureFieldType(fdef["type"]),
                    assigned_signer_id=user_sub,
                    required=True,
                    default_value=populated.get(fdef["id"]),
                )
            results.append({
                "template_type": tmpl["template_type"],
                "packet_id": packet_id,
                "version": tmpl["version"],
            })
        return results

    def auto_populate_fields(self, *, template: dict,
                              profile: dict) -> dict[str, str]:
        """Map auto_populate hints to actual profile values."""
        out: dict[str, str] = {}
        for fdef in template.get("fields", []):
            hint = fdef.get("auto_populate")
            if hint and hint in profile:
                out[fdef["id"]] = str(profile[hint] or "")
        return out

    def get_template_version(self, template_type: str) -> str:
        return KYC_TEMPLATE_TYPES[template_type]["version"]

    def check_version_migration(self, *, case: dict) -> list[dict]:
        """Return list of {template_type, current_version, signed_version}
        for templates that need re-signing."""
        stale = []
        for tp in list(case.get("signature", {}).get("template_packets", [])):
            current = self.get_template_version(tp["template_type"])
            if tp.get("version") != current:
                stale.append({
                    "template_type": tp["template_type"],
                    "signed_version": tp.get("version"),
                    "current_version": current,
                })
        return stale

    def add_witness_signer(self, *, packet_id: str,
                            witness_sub: str) -> dict:
        """Add admin as witness co-signer. Appends WITNESS_FIELDS."""
        for fdef in WITNESS_FIELDS:
            upsert_packet_field(
                packet_id=packet_id,
                field_id=fdef["id"],
                page=1,
                x=0.0, y=0.0, width=200.0, height=30.0,
                field_type=SignatureFieldType(fdef["type"]),
                assigned_signer_id=witness_sub,
                required=True,
            )
        return add_signer(
            packet_id=packet_id,
            signer_id=witness_sub,
            role="witness",
        )

    def _load_profile(self, user_sub: str) -> dict:
        resp = T.users.get_item(Key={"pk": f"USER#{user_sub}", "sk": "PROFILE"})
        return resp.get("Item") or {}
```

### 4.2 Dev/Prod parity (SECOPS-007)

- The service reads from `T.users` (DynamoDB) and calls `create_draft_packet` /
  `upsert_packet_field`. Both are already moto-backed in dev (via `app/core/tables.py` and
  `app/core/dev_s3.py`). No AWS-specific path diverges.
- `signature_pdf_enabled` flag (`app/services/signature_packet_flags.py`) is already
  enforced inside `create_draft_packet` and `upsert_packet_field`. The new service calls
  those primitives directly, so the feature flag gates it automatically — no separate flag
  required.
- The `upsert_packet_field` signature currently lacks a `default_value` parameter (see
  `app/services/signature_packet_store.py:133`). The fix must add this optional kwarg with
  a `None` default and store it in the DDB item when provided.

### 4.3 Backward compatibility

No existing API surface changes. The new service is additive. Existing single-packet
`case["signature"]["packet_id"]` path (used by `_signature_status_for_case` at
`app/routers/kyc_cases.py:205`) is unaffected because the new template packets are stored
under `case["signature"]["template_packets"]` (GAP-0264 concern). The legacy gate
continues to function until the template flow is adopted.

### 5.1 Offline regression test (pytest)

```python
# tests/services/test_kyc_signature_templates.py
import pytest
from unittest.mock import patch, MagicMock
from app.services.kyc_signature_templates import KycSignatureTemplateService, KYC_TEMPLATE_TYPES

@pytest.fixture
def svc():
    return KycSignatureTemplateService()

def test_get_required_templates_standard(svc):
    result = svc.get_required_templates(intake_profile="standard")
    types = {t["template_type"] for t in result}
    assert types == {"terms_of_service", "aml_declaration", "data_consent"}

def test_get_required_templates_high_risk_returns_all(svc):
    result = svc.get_required_templates(intake_profile="high_risk")
    assert len(result) == 5

def test_auto_populate_fields_maps_display_name(svc):
    tmpl = KYC_TEMPLATE_TYPES["terms_of_service"]
    profile = {"display_name": "Alice Smith", "date_of_birth": "1990-01-01"}
    populated = svc.auto_populate_fields(template=tmpl, profile=profile)
    assert populated["full_name"] == "Alice Smith"
    assert populated["date_of_birth"] == "1990-01-01"

def test_check_version_migration_detects_stale(svc):
    case = {"signature": {"template_packets": [
        {"template_type": "terms_of_service", "version": "OLD-v0", "packet_id": "p1"}
    ]}}
    stale = svc.check_version_migration(case=case)
    assert len(stale) == 1
    assert stale[0]["template_type"] == "terms_of_service"
    assert stale[0]["current_version"] == KYC_TEMPLATE_TYPES["terms_of_service"]["version"]

def test_check_version_migration_no_stale_when_current(svc):
    current_ver = KYC_TEMPLATE_TYPES["terms_of_service"]["version"]
    case = {"signature": {"template_packets": [
        {"template_type": "terms_of_service", "version": current_ver, "packet_id": "p1"}
    ]}}
    stale = svc.check_version_migration(case=case)
    assert stale == []
```
