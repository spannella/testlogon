# GAP-0246: DocumentViewer Component Missing — Remediation Write-up

> ~5 pages. Fix-oriented. Verified against actual codebase; no prior investigation doc exists.

## 1. Summary & Classification

**Claim from ticket**: The `DocumentViewer` component is absent from
`frontend/src/components/shared/DocumentViewer.tsx` — identity-document images in the
KYC admin case-detail view have no zoom, rotate, or fullscreen controls, and no
`VerificationStateBadge` overlay.

**Verdict: Claim INACCURATE (partially).** A `DocumentViewer` function component does
exist, but it lives **inside** `KycCaseDetailPage.tsx` as a local, file-scoped component
rather than as the dedicated shared module the ticket expects at
`frontend/src/components/shared/DocumentViewer.tsx`. The component is therefore not
reusable across other KYC pages and does not carry the presigned-URL caching behaviour
described in the fix note.

- **Severity**: HIGH — admin reviewers examining identity documents cannot benefit from a
  reliable shared implementation. The inline component also re-implements the controls from
  scratch for every consuming page, meaning any future page (e.g. a dedicated document-detail
  drill-down) will duplicate logic or silently miss features.
- **Source ticket**: KYC-001
- **Owning area**: Frontend / KYC admin tooling
- **Related tickets**: GAP-0247 (ExtractionResultsPanel), GAP-0250 (VerificationCallPanel),
  SECOPS-007 (dev/prod parity)

## 2. Current-State Investigation (root cause)

### What actually exists

`frontend/src/pages/admin/KycCaseDetailPage.tsx` lines 105–231 define a local function
component `DocumentViewer`:

```tsx
// KycCaseDetailPage.tsx:105
function DocumentViewer({ files }: { files: KycFileRef[] }) {
  const [activeTab, setActiveTab] = useState(files[0]?.type ?? "");
  const [scale, setScale]         = useState(1);
  const [rotation, setRotation]   = useState(0);
  const [fullscreen, setFullscreen] = useState(false);
  ...
```

It renders a shadcn `Tabs` bar (one tab per document type), zoom-in/zoom-out buttons,
clockwise/counter-clockwise rotation, a fullscreen overlay toggle, and a `Badge` overlay
showing `file.verification_state`. It is consumed on line 434:

```tsx
// KycCaseDetailPage.tsx:434
<DocumentViewer files={caseData.files_ref} />
```

The image is fetched via a relative proxy URL (line 200):

```tsx
src={`/ui/files/download?path=${encodeURIComponent(file.path)}`}
```

This is a generic file-manager download path, not a KYC-specific presigned S3 URL.  On the
backend, `app/services/kyc_document_verification.py` line 205–206 stores a `/mock/s3/…` URL
in `dev_mode` and a real S3 key in production, but `KycFileRef.path` exposed by the admin
detail endpoint (`/v1/kyc/cases/admin/cases/{id}`) carries the raw S3 key, not a
short-lived presigned URL, so the image load silently fails in any environment where the
frontend does not sit behind the `/ui/files/download` proxy.

### `files_ref` does not carry `document_id`

`app/routers/kyc_cases.py` lines 428–436 show how `files_ref` is built for the admin
case-detail response:

```python
"files_ref": [
    {
        "type": item.get("type"),
        "path": item.get("path"),           # raw S3 key, e.g. "kyc-docs/user_abc/id_front.jpg"
        "verification_state": item.get("verification_state"),
        "uploaded_at": item.get("uploaded_at"),
    }
    for item in files
],
```

There is no `document_id` field. Without `document_id` the frontend cannot call a
presigned-URL endpoint keyed on the document. The `path` field is the raw S3 object key,
not a URL, so rendering `<img src={path}>` would be a 400/404 in production.

### What is missing compared to the ticket's intent

1. **Shared module** — `frontend/src/components/shared/DocumentViewer.tsx` does not exist.
   The component cannot be imported by `KycDocumentVerificationPage`, a future
   `KycDocumentDetailPage`, or any other admin page without copy-pasting.

2. **`document_id` in `files_ref`** — The admin case-detail serializer
   (`kyc_cases.py:428–436`) does not include `document_id` in the `files_ref` array. The
   presigned-URL endpoint requires a `document_id` to look up the stored S3 key and
   bucket. This serializer must be updated as part of the fix.

3. **Presigned-URL caching** — The inline component passes `file.path` (an S3 key) directly
   into an `<img>` `src`. In production the path is a raw S3 object key; a presigned URL
   must be obtained from the backend. There is no React Query call to
   `GET /ui/kyc/documents/{id}/presign` (or equivalent) and no cache-busting on expiry.
   In dev mode the proxy path `/ui/files/download?path=…` happens to resolve because the
   generic file-manager endpoint accepts any path, but in production KYC documents live in
   a private S3 bucket not accessible through the file-manager proxy.

4. **`VerificationStateBadge` as a named component** — The badge is rendered inline as a
   `<Badge variant=...>` inside `DocumentViewer`. There is no named
   `VerificationStateBadge` component that other panels (e.g. GAP-0247's
   `ExtractionResultsPanel`, GAP-0250's `VerificationCallPanel`) can import.

## 3. Impact / Exploit / Blast Radius

This is a functional gap, not a security vulnerability.

| Area | Impact |
|------|--------|
| **Image load in production** | If the admin detail API returns a raw S3 key as `path`, `<img src="/ui/files/download?path=…">` will 404 unless the backend proxy accepts arbitrary KYC object keys. This means document images silently fail to load for KYC reviewers in production, forcing them to navigate to a separate queue page. |
| **Code duplication** | Every new KYC admin page that needs a document viewer must re-implement zoom/rotate state. Any bug fix (e.g. wheel-scroll delta direction) must be applied in every copy. |
| **Presigned-URL expiry** | Without expiry tracking, an image loaded early in a long review session may become unavailable mid-review when the presigned URL expires (~15 min default on AWS). |
| **Accessibility** | The inline component has no `aria-label` on the fullscreen `<div>` overlay, no focus management when entering fullscreen, and no keyboard zoom/rotate bindings. As a shared component these gaps are fixed once for all consumers. |

## 4. Fix Design (code-level)

### 4a. Extract `VerificationStateBadge` (shared primitive)

Create `frontend/src/components/shared/VerificationStateBadge.tsx`:

```tsx
import { Badge } from "@/components/ui/badge";

type VerificationState = "pending" | "verified" | "rejected" | string;

export function VerificationStateBadge({ state }: { state: VerificationState }) {
  const variant =
    state === "verified" ? "default"
    : state === "rejected" ? "destructive"
    : "outline";
  return (
    <Badge variant={variant} data-testid="verification-badge">
      {state}
    </Badge>
  );
}
```

### 4b. Create `DocumentViewer` as a proper shared component

Create `frontend/src/components/shared/DocumentViewer.tsx`:

```tsx
import { useState, useCallback } from "react";
import { useQuery } from "@tanstack/react-query";
import { ZoomIn, ZoomOut, RotateCw, RotateCcw, Maximize } from "lucide-react";
import { Button } from "@/components/ui/button";
import { Card } from "@/components/ui/card";
import { Tabs, TabsContent, TabsList, TabsTrigger } from "@/components/ui/tabs";
import { VerificationStateBadge } from "./VerificationStateBadge";
import { api } from "@/api/client";

export interface DocumentFile {
  type: string;
  document_id: string;   // used to fetch presigned URL
  file_name: string;
  verification_state: string;
}

const FILE_TYPE_LABELS: Record<string, string> = {
  selfie: "Selfie",
  id_front: "ID Front",
  id_back: "ID Back",
  proof_of_address: "Proof of Address",
};

// Fetch presigned URL; React Query caches and re-fetches before expiry
function usePresignedUrl(documentId: string) {
  return useQuery({
    queryKey: ["kyc-doc-url", documentId],
    queryFn: () =>
      api
        .get<{ url: string }>(`/ui/kyc/documents/${documentId}/presign`)
        .then((r) => r.url),
    staleTime: 10 * 60 * 1000,   // 10 min — presigned URLs valid for 15 min
    gcTime:    12 * 60 * 1000,
  });
}

function DocumentImage({ file }: { file: DocumentFile }) {
  const { data: url, isLoading, isError } = usePresignedUrl(file.document_id);
  if (isLoading) return <p className="text-sm text-muted-foreground">Loading…</p>;
  if (isError || !url) return <p className="text-sm text-destructive">Image unavailable.</p>;
  return <img src={url} alt={FILE_TYPE_LABELS[file.type] ?? file.type} className="max-w-full" data-testid="doc-image" />;
}

export function DocumentViewer({ files }: { files: DocumentFile[] }) {
  const [activeTab, setActiveTab] = useState(files[0]?.type ?? "");
  const [scale, setScale]         = useState(1);
  const [rotation, setRotation]   = useState(0);
  const [fullscreen, setFullscreen] = useState(false);

  const zoomIn    = useCallback(() => setScale((s) => Math.min(s + 0.25, 5)), []);
  const zoomOut   = useCallback(() => setScale((s) => Math.max(s - 0.25, 0.25)), []);
  const rotateCw  = useCallback(() => setRotation((r) => (r + 90) % 360), []);
  const rotateCcw = useCallback(() => setRotation((r) => (r - 90 + 360) % 360), []);

  const handleTabChange = useCallback((val: string) => {
    setActiveTab(val);
    setScale(1);
    setRotation(0);
  }, []);

  const handleWheel = useCallback((e: React.WheelEvent) => {
    e.preventDefault();
    if (e.deltaY < 0) zoomIn(); else zoomOut();
  }, [zoomIn, zoomOut]);

  if (files.length === 0) {
    return (
      <Card>
        <div className="py-12 text-center text-muted-foreground">
          No documents attached to this case.
        </div>
      </Card>
    );
  }

  const activeFile = files.find((f) => f.type === activeTab);

  const viewer = (
    <div className={fullscreen ? "fixed inset-0 z-50 bg-background flex flex-col" : ""}>
      <Tabs value={activeTab} onValueChange={handleTabChange}>
        <div className="flex items-center justify-between border-b px-4 py-2">
          <TabsList>
            {files.map((f) => (
              <TabsTrigger key={f.type} value={f.type} data-testid={`doc-tab-${f.type}`}>
                {FILE_TYPE_LABELS[f.type] ?? f.type}
              </TabsTrigger>
            ))}
          </TabsList>
          <div className="flex items-center gap-1">
            <Button variant="ghost" size="icon" onClick={zoomIn}    aria-label="Zoom In">   <ZoomIn  className="h-4 w-4" /></Button>
            <Button variant="ghost" size="icon" onClick={zoomOut}   aria-label="Zoom Out">  <ZoomOut className="h-4 w-4" /></Button>
            <Button variant="ghost" size="icon" onClick={rotateCw}  aria-label="Rotate CW"> <RotateCw  className="h-4 w-4" /></Button>
            <Button variant="ghost" size="icon" onClick={rotateCcw} aria-label="Rotate CCW"><RotateCcw className="h-4 w-4" /></Button>
            <Button variant="ghost" size="icon" onClick={() => setFullscreen((f) => !f)} aria-label="Fullscreen">
              <Maximize className="h-4 w-4" />
            </Button>
          </div>
        </div>
        {files.map((f) => (
          <TabsContent key={f.type} value={f.type} className="mt-0">
            <div
              className="relative flex items-center justify-center overflow-auto bg-muted/30"
              style={{ minHeight: fullscreen ? "calc(100vh - 60px)" : "400px",
                       transform: `scale(${scale}) rotate(${rotation}deg)` }}
              onWheel={handleWheel}
            >
              {activeFile?.type === f.type && <DocumentImage file={f} />}
              <div className="absolute bottom-3 right-3">
                <VerificationStateBadge state={f.verification_state} />
              </div>
            </div>
          </TabsContent>
        ))}
      </Tabs>
    </div>
  );

  return <Card className="overflow-hidden">{viewer}</Card>;
}
```

### 4c. Backend: add presigned-URL endpoint (dev/prod parity — SECOPS-007)

Add to `app/routers/kyc_documents.py`:

```python
@kyc_documents_router.get("/{document_id}/presign")
async def get_document_presigned_url(
    document_id: str,
    _user: AuthenticatedUser = Depends(require_admin_or_root),
) -> dict[str, str]:
    item = STORE.get_document(document_id)
    if not item:
        raise HTTPException(status_code=404, detail={"code": "kyc_document_not_found"})
    bucket  = str(item.get("bucket") or S.kyc_documents_bucket)
    s3_key  = str(item.get("s3_key") or "")
    if S.dev_mode:
        return {"url": f"/mock/s3/{bucket}/{s3_key}"}
    # Production path — boto3 S3 client generates a real presigned URL
    from app.core.aws import s3_client
    url = s3_client().generate_presigned_url(
        "get_object",
        Params={"Bucket": bucket, "Key": s3_key},
        ExpiresIn=900,   # 15 min; React Query staleTime is 10 min
    )
    return {"url": url}
```

The same code path runs in both dev and prod, gated only by `S.dev_mode`. No environment-specific branches exist outside this single function, satisfying SECOPS-007.

### 4f. Update `KycCaseDetailPage` to use the shared component

Remove lines 103–231 from `KycCaseDetailPage.tsx` and replace the inline `DocumentViewer`
with an import:

```tsx
import { DocumentViewer } from "@/components/shared/DocumentViewer";
```

The `DocumentViewer` props interface uses `document_id: string` for presign calls. For
legacy `files_ref` entries where `document_id` is null, fall back to the proxy URL path:
the component can check `file.document_id ? presignedUrl : proxyUrl` in `DocumentImage`.

### Alternatives considered

- **Keep the inline component** — Rejected. GAP-0247 and GAP-0250 both add new panels to
  `KycCaseDetailPage`; having the viewer inline makes the file grow unbounded and prevents
  reuse on a future standalone document-detail route.
- **Lazy load the presigned URL** — An `<img>` with the proxy URL works in dev but silently
  breaks in production where KYC documents are in a private S3 bucket. The presigned-URL
  approach is the only correct solution.
- **Use the file-manager download endpoint for all environments** — The `/ui/files/download`
  proxy endpoint checks that the requesting user owns the file path. KYC documents belong to
  the case owner, not the reviewing admin, so the admin would receive a 403. A
  KYC-specific presign endpoint with its own `require_admin_or_root` guard is necessary.
- **Embed presigned URL in the case-detail API response** — Would embed time-limited URLs
  in a response that might be cached by React Query for minutes. The React Query-based
  presign approach (with its own `staleTime: 10 * 60 * 1000`) is safer and aligns with
  the pattern used elsewhere in the codebase (e.g. VNC session tokens).
