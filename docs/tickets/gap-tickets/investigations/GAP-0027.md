# GAP-0027 Investigation: DMCA waiting-period background timer not wired to startup

## Verdict

**Confirmed** — `process_expired_dmca_waiting_periods()` at
`app/services/dmca_claims.py:617` is fully implemented (scans the `ByWaitingPeriodExpiry` GSI,
resolves expired claims, restores content) but is **never registered as a background task**.

`app/main.py` lines 482–483 only include the DMCA routers; no `add_event_handler("startup", ...)`
call for any DMCA timer appears anywhere in the codebase.  Searched all of `app/` for
`_dmca_timer`, `dmca_timer_loop`, `start_dmca`, `process_expired_dmca` — only the function
definition was found.

## Root Cause

The `process_expired_dmca_waiting_periods` function was implemented in the service layer per the
ticket spec (section 3.7 references a background loop) but the wiring step — creating an async
loop wrapper and registering it with `add_event_handler("startup", ...)` in `main.py` — was
omitted.  Every other periodic job in the codebase (deletion scheduler, billing dunning, scheduled
messages, etc.) follows the same startup-registration pattern; DMCA alone was missed.

## Exact Fix

1. Add an async loop wrapper to `app/routers/dmca.py` (or a new
   `app/services/dmca_timer.py`):

```python
import asyncio
import logging
from app.services.dmca_claims import process_expired_dmca_waiting_periods

logger = logging.getLogger(__name__)
_DMCA_TIMER_INTERVAL_SECONDS = 3600  # check hourly

async def _dmca_timer_loop() -> None:
    while True:
        try:
            processed = process_expired_dmca_waiting_periods()
            if processed:
                logger.info("dmca_timer: auto-resolved %d expired waiting periods", processed)
        except Exception:
            logger.exception("dmca_timer: unhandled error")
        await asyncio.sleep(_DMCA_TIMER_INTERVAL_SECONDS)

def start_dmca_timer_task() -> None:
    asyncio.get_event_loop().create_task(_dmca_timer_loop())
```

2. In `app/main.py`, import and register:

```python
# Near line 482, alongside other DMCA router imports:
from app.routers.dmca import start_dmca_timer_task  # (or from app.services.dmca_timer)
# ...
app.add_event_handler("startup", start_dmca_timer_task)
```

## Blast Radius / Exploit

**Legal compliance**: When a user files a valid DMCA counter-notice, US 17 U.S.C. § 512(g)(2)
requires the platform to restore content after the 10–14 business day waiting period unless the
original claimant files suit.  Without the background timer, claims in `waiting_period` status
never transition to `resolved` and content is never automatically restored.  This exposes the
platform to wrongful-takedown liability.

There is no direct security exploit, but an attacker who files a DMCA claim can permanently
suppress legitimate content.
