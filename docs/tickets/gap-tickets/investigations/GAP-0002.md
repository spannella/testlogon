# GAP-0002 Investigation: serve_broadcast_ad stub not wired to ADS-004 engine

**Verdict**: Confirmed

---

## Evidence

`app/services/broadcast_ads.py` lines 55–83 — `serve_broadcast_ad()` is explicitly a stub with a comment that says it should delegate to `app.services.ad_serving.serve_ad` when ADS-004 lands:

```python
def serve_broadcast_ad(
    *,
    surface: str,
    creator_id: str,
    content_id: str,
    slot_type: str,
    user_id: str,
) -> Dict[str, Any]:
    """Select an ad for a broadcast surface.

    NOTE: ADS-004 (ad serving engine) and ADS-002 (video creatives) are not yet
    implemented. This returns a deterministic stub "house" creative so the rest of
    the flow (overlay, tracking, skip) is exercisable end-to-end. When ADS-004 lands
    this function should delegate to ``app.services.ad_serving.serve_ad``.
    ...
    """
    creative_id = f"bcast_house_{slot_type}"
    return {
        "filled": True,
        "creative_id": creative_id,
        "format": "video",
        "video_url": f"/mock/s3/ad-creatives/{creative_id}.mp4",
        ...
    }
```

Meanwhile, `app/services/ad_serving.py` (ADS-004) is fully implemented — `serve_ad()` exists at line 45 with targeting, frequency caps, budget enforcement, fraud detection, and creative selection.

The stub comment says "ADS-004 does not exist yet" but the ADS-004 engine is now live. The delegation was never completed.

---

## Root Cause

`serve_broadcast_ad()` was written as a placeholder before `ad_serving.serve_ad()` existed. After ADS-004 was implemented (`app/services/ad_serving.py`), the broadcast service was never updated to call the real engine. All broadcast viewers therefore see the same hardcoded house video creative regardless of targeting, frequency caps, or budget.

---

## Exact Fix

Replace the stub body of `serve_broadcast_ad()` with delegation to `serve_ad()`:

```python
def serve_broadcast_ad(
    *,
    surface: str,
    creator_id: str,
    content_id: str,
    slot_type: str,
    user_id: str,
) -> Dict[str, Any]:
    """Select an ad for a broadcast surface via the ADS-004 serving engine."""
    from app.services.ad_serving import serve_ad
    try:
        return serve_ad(
            surface=surface,
            content_type="broadcast",
            creator_id=creator_id,
            content_id=content_id,
            slot_type=slot_type,
            user_id=user_id,
        )
    except Exception:
        # Graceful degradation: fall back to house ad on engine failure
        creative_id = f"bcast_house_{slot_type}"
        return {
            "filled": True,
            "creative_id": creative_id,
            "format": "video",
            "video_url": f"/mock/s3/ad-creatives/{creative_id}.mp4",
            "image_url": None,
            "cta_url": None,
            "impression_url": f"/broadcast/sessions/{content_id}/ads/{creative_id}/track?event=impression",
            "click_url": f"/broadcast/sessions/{content_id}/ads/{creative_id}/track?event=click",
            "skip_url": f"/broadcast/sessions/{content_id}/ads/{creative_id}/track?event=skip",
        }
```

The graceful degradation fallback preserves the existing house-ad behavior when the engine is unavailable (e.g., no active campaigns).

---

## Blast Radius / Exploit

All broadcast viewers receive the same house creative. No targeting, no frequency cap enforcement, no budget pacing, and no revenue generation for advertisers or creators. Advertisers cannot reach broadcast audiences despite active campaigns. The monetization path for broadcast ad breaks is entirely dead.

## Regression Test

**pytest (offline)**

```python
# tests/test_broadcast_ads.py
from unittest.mock import patch, MagicMock

def test_serve_broadcast_ad_delegates_to_engine():
    mock_result = {"filled": True, "creative_id": "cmp_creative_001", "format": "video",
                   "video_url": "/cdn/creative.mp4", "impression_url": "/track?event=impression",
                   "click_url": "/track?event=click", "skip_url": "/track?event=skip"}
    with patch("app.services.ad_serving.serve_ad", return_value=mock_result) as mock_serve:
        from app.services.broadcast_ads import serve_broadcast_ad
        result = serve_broadcast_ad(
            surface="broadcast", creator_id="creator_1",
            content_id="session_1", slot_type="broadcast_preroll", user_id="user_1"
        )
    mock_serve.assert_called_once()
    assert result["creative_id"] == "cmp_creative_001"
    assert not result.get("creative_id", "").startswith("bcast_house_")
```

Before the fix: `serve_ad` is never called, `creative_id` is `"bcast_house_broadcast_preroll"`.
After the fix: `serve_ad` is called, returns engine-selected creative.
