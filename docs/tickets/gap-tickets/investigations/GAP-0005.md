# GAP-0005 Investigation: elevate_feed_items() not called from newsfeed router

**Verdict**: Confirmed

---

## Evidence

`app/services/content_boost.py` lines 409–433 — `elevate_feed_items()` is fully implemented:

```python
def elevate_feed_items(
    items: list[dict[str, Any]],
    *,
    content_type: str = "post",
    id_key: str = "content_id",
    score_key: str = "score",
    now: int | None = None,
) -> list[dict[str, Any]]:
    """Re-rank a list of feed items, elevating actively-boosted content."""
    out: list[dict[str, Any]] = []
    for it in items:
        copy = dict(it)
        base = int(copy.get(score_key, 0) or 0)
        bonus = boost_rank_bonus(content_type, str(copy.get(id_key, "")), now=now)
        copy["is_boosted"] = bonus > 0
        copy["effective_score"] = base + bonus
        out.append(copy)
    out.sort(key=lambda x: x["effective_score"], reverse=True)
    return out
```

`app/routers/newsfeed.py` lines 5133–5161 — the `GET /feed` handler builds `feed_items`, then calls `_inject_sponsored_posts()` (ADS-005 sponsored posts), but never calls `elevate_feed_items()`:

```python
# ADS-005: Inject sponsored posts into the feed
feed_items = ordered[:limit]
if not author_filter:  # Only inject in the main feed, not author-filtered views
    feed_items = _inject_sponsored_posts(feed_items, user_id)

out = {"items": feed_items, "next_cursor": encode_cursor(next_eks)}
```

A codebase-wide search confirms `elevate_feed_items` has exactly one definition (`content_boost.py:409`) and zero call sites:

```
grep -rn "elevate_feed_items" app/
app/services/content_boost.py:409:def elevate_feed_items(
```

It is never imported or called from `newsfeed.py` or any other router/service.

---

## Root Cause

`elevate_feed_items()` was implemented in `content_boost.py` as part of the boost feature, but the wiring step — calling it from the `GET /feed` handler after organic post assembly — was never completed. Boosts are created and charged, but their re-ranking effect on the feed is never applied.

---

## Exact Fix

In `app/routers/newsfeed.py`, after assembling `feed_items` and before returning, call `elevate_feed_items()`. The feed items use `"post_id"` as the ID key (not `"content_id"`):

```python
# ADS-012: Elevate boosted posts in the feed
from app.services.content_boost import elevate_feed_items

feed_items = ordered[:limit]
if not author_filter:
    feed_items = _inject_sponsored_posts(feed_items, user_id)
    feed_items = elevate_feed_items(feed_items, content_type="post", id_key="post_id")
```

Note: `elevate_feed_items` uses `id_key="content_id"` by default, but newsfeed post dicts carry `"post_id"`. The call must pass `id_key="post_id"` explicitly, otherwise `boost_rank_bonus()` will look up boost by empty string and return 0 for all items (silently broken).

Also verify that `sort_posts_deterministically()` (called earlier in the handler) does not conflict: `elevate_feed_items` produces a new sorted list by effective score, so it should run after `sort_posts_deterministically` and after filter/blocking/pagination, on the final assembled `feed_items` list.

---

## Blast Radius / Exploit

Every creator who paid to boost a post is being charged for a service that has no effect. The boost is stored, the charge fires, but the feed rank is unchanged. This is a billing/trust violation: creators can reasonably demand refunds for all boosts sold since the feature was deployed. Additionally, advertisers who rely on post visibility via boosts receive zero return.

## Regression Test

**pytest (offline)**

```python
# tests/test_feed_boost_elevation.py
from unittest.mock import patch
from app.services.content_boost import elevate_feed_items, BOOST_RANK_WEIGHT

def test_elevate_feed_items_reranks_boosted_post():
    items = [
        {"post_id": "p1", "score": 5},
        {"post_id": "p2", "score": 10},  # higher organic score
    ]
    def mock_bonus(content_type, content_id, now=None):
        return BOOST_RANK_WEIGHT if content_id == "p1" else 0

    with patch("app.services.content_boost.boost_rank_bonus", side_effect=mock_bonus):
        result = elevate_feed_items(items, id_key="post_id")

    assert result[0]["post_id"] == "p1"  # boosted post elevated above p2
    assert result[0]["is_boosted"] is True
    assert result[1]["post_id"] == "p2"
```

**Integration (Playwright/E2E):** Create a boost for a post with low organic rank, then call `GET /feed` and verify the boosted post appears before higher-organic-score posts, and that `is_boosted: true` is present in the response.
