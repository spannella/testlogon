# GAP-0118: SEC-010

**Status**: Open · **Severity**: HIGH (High) · **Source ticket**: BCAST-005 · **Effort**: S
**From**: gap audit (`docs/tickets/gaps/BCAST-005.md`); see also `docs/tickets/writeups/BCAST-005.md`

## Location
`_chat_msg_out`

## Problem / Impact
locked message text delivered in clear to all stream subscribers; paywall bypassed

## Fix
pass `viewer_user_id=ctx["user_sub"]` to `_chat_msg_out(msg, ...)` in the chat stream generator

## Notes
This gap was identified by the second-pass as-built review of BCAST-005. Apply the dev/prod
parity rules in SECOPS-007 if the fix touches AWS-backed paths. Add a regression test
(pytest offline / Playwright) that fails before the fix and passes after.
