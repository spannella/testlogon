# FIN-007 Writeup: Platform Commission Visibility — UNBUILT

## Status
UNBUILT — no implementation exists.

## What the ticket requires
FIN-007 adds transparent platform commission visibility: a `platform_commission.py` service storing commission rates in DynamoDB, a `platform_commission.py` router exposing four endpoints (`GET /ui/commission/rates`, `PUT /ui/commission/rates`, `GET /ui/commission/rates/audit`, `GET /ui/commission/summary`), enhanced billing ledger entries that carry `gross_amount_cents`, `platform_fee_cents`, and `platform_fee_pct` in `meta`, a `CommissionPage.tsx` frontend, and admin-only rate editing with an audit log.

## What exists
- `app/services/billing_shared.py:217` — `new_ledger_entry` accepts an extensible `meta` dict but **no commission fields are written** anywhere.
- `app/services/tip_ledger.py:88` — tips are credited at full gross with no platform fee deduction.
- `app/routers/broadcast.py:3150` — one isolated hardcoded `platform_fee_pct=20` in broadcast revenue split; not a general system.
- `app/routers/license_revenue.py:91` — license revenue fee (`S.license_revenue_platform_fee_pct`) is applied in one path but not stored in ledger meta.
- `app/models.py:9285-9286` — `gross_amount_cents`/`platform_fee_cents` fields exist on a `SyndicateRevenueSplitIn` model only, not on general ledger models.
- No `app/services/platform_commission.py` file.
- No `app/routers/platform_commission.py` file.
- No `CommissionPage.tsx` or `commission.ts` frontend files.
- No `COMMISSION_RATES` DDB record.
- No `COMMISSION_VISIBILITY_ENABLED` feature flag in `app/core/settings.py`.

## SEC-004 cross-reference
Commission deduction touches the money path (tip ledger debits/credits). Per SEC-004, the tip debit+credit should be atomic (DDB TransactWrite). The commission calculation must happen before the credit is written and the fee amount must be stored immutably in the ledger entry's `meta` — rate changes must never retroactively alter historical entries. The `calculate_commission` function must use integer floor arithmetic only (no floats).

## SECOPS-007 parity
- All commission rate changes must be audit-logged (actor ID, before/after snapshot, timestamp).
- `PUT /ui/commission/rates` requires `require_admin_session`.
- `GET /ui/commission/rates/audit` requires `require_admin_session`.
- Commission summary is scoped to the authenticated caller's `user_sub` — no cross-user access.

## Fee calculation rule
```
fee = floor(gross * rate_pct / 100)
fee = max(fee, min_fee_cents) if min_fee > 0
fee = min(fee, max_fee_cents)  if max_fee > 0
net = gross - fee
assert net + fee == gross  # invariant
```
