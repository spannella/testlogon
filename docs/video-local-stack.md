# Local Video Stack (`docker-compose.video.local.yml`) — VWD-005

This stack provides an open-source local environment for end-to-end video workflows without AWS.

## Services

- `ingest`: RTMP ingress endpoint (`tiangolo/nginx-rtmp`) on `:1935`.
- `transcoder`: FFmpeg pipeline generating live HLS segments/manifests under `video-data/hls`.
- `packager`: local packaging placeholder that emits DASH manifest under `video-data/dash`.
- `origin`: NGINX static origin serving `video-data` on `http://localhost:8089/`.
- `license-mock`: local mock DRM license endpoint on `http://localhost:8090/license`.

## Volumes and artifacts

- `./video-data/input`
- `./video-data/hls`
- `./video-data/dash`
- `./video-data/logs`

## Start

```bash
docker compose -f docker-compose.video.local.yml up -d
```

## Health checks

- Ingest: `http://localhost:8088/`
- Origin: `http://localhost:8089/healthz`
- License mock: `http://localhost:8090/healthz`
- HLS manifest (generated by transcoder): `http://localhost:8089/hls/master.m3u8`
- DASH manifest (generated by packager): `http://localhost:8089/dash/manifest.mpd`

## Stop

```bash
docker compose -f docker-compose.video.local.yml down
```


## Stream routing

- Ingest accepts RTMP at `rtmp://localhost:1935/live/<stream_key>`.
- Default stream key is `localdemo`.
- Transcoder pulls from `rtmp://ingest/live/localdemo` inside the compose network.

Push a sample stream from host:

```bash
./scripts/video/push_sample_stream.sh localdemo
```

## Input loss and reconnect behavior

- If the ingest source disconnects, FFmpeg exits and the transcoder entrypoint retries every 2 seconds.
- When input returns on the same stream key, transcoding resumes automatically and HLS output is regenerated.


## ABR + watermark pipeline

The transcoder launches one FFmpeg worker per canonical rendition (`1080p`, `720p`, `540p`, `360p`) using `scripts/video/run_abr_transcoder.py`.

Watermark policy env vars consumed by the transcoder:

- `WATERMARK_MODE` (`dynamic_text` or `static_image` or `none`)
- `WATERMARK_TEXT_TEMPLATE`
- `WATERMARK_ASSET_URI`
- `WATERMARK_POSITION`, `WATERMARK_OPACITY`, `WATERMARK_MARGIN_X`, `WATERMARK_MARGIN_Y`

Outputs:

- Rendition playlists: `video-data/hls/<rendition>/index.m3u8`
- Master playlist: `video-data/hls/master.m3u8`


## Packaging (HLS + DASH)

The local packager loop runs `scripts/video/package_manifests.py` and writes:

- HLS master: `video-data/hls/master.m3u8`
- DASH manifest: `video-data/dash/manifest.mpd`
- Shaka config template: `config/video/shaka_packager_config.json`

Manifest path conventions follow the contract:

- HLS variant: `hls/<rendition>/index.m3u8`
- DASH manifest: `dash/manifest.mpd`
- DASH representation ID: `v_<rendition>`


## Mock DRM clear-key flow

Issue a sample entitlement token:

```bash
./scripts/video/generate_sample_entitlement_token.py
```

Request a license with token (success path):

```bash
curl -s http://localhost:8090/entitlement \
  -H 'content-type: application/json' \
  -d '{"asset_id":"asset_local_demo_001","tenant_id":"dev-tenant","session_id":"session-1","device_id":"device-1","profile":"multi_drm"}'
```

Then call `/license` with `Authorization: Bearer <token>` and the matching request payload.

Failure paths to test:

- expired token (`ttl_seconds` very low then delay request)
- invalid signature (tamper token)
- claim mismatch (change `asset_id` or `device_id` between token and license request)


## One-command demo scripts

- Push live sample stream:
  - `./scripts/video/push_sample_stream.sh localdemo`
