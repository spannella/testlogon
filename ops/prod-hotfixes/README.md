# Prod backend hotfixes (live, applied out-of-band)

These are surgical patches applied directly to the **running production backend**
(`/home/ubuntu/testlogon` on the prod EC2, reachable only via AWS SSM) during the
Android-app QA sessions of June 2026. They were applied as live string-anchored edits,
**not** through this git repo, so they are recorded here so they are not lost on the next
prod redeploy.

## IMPORTANT: branch divergence

The prod backend is a **different, much larger** codebase than this `android-impl` branch's
`app/`. Measured divergence of prod vs this branch HEAD (`3afa49b9`):

| file | differing lines | note |
|------|-----------------|------|
| `app/models.py` | 8620 (prod +8600 lines) | prod runs a vastly expanded models module |
| `app/routers/messaging.py` | 1068 (prod +742) | |
| `app/routers/newsfeed.py` | 505 | prod has NRS-003 (`_recsys_engage`) etc. not on this branch |
| `app/services/filemanager.py` | 302 | |
| `app/routers/billing.py` | 177 | |
| `app/routers/filemanager.py` | 149 | |
| `app/services/push.py` | 37 | ≈ just the FCM hotfix below |
| `app/services/activity_feed.py` | 43 | ≈ just the social-hook helper |
| `app/routers/social.py` | 5 | ≈ just the follow hook |

Because of this, the hotfixes **cannot be cleanly merged into `android-impl`** — they belong
on whatever branch prod actually deploys from. These `.patch` files were generated by diffing
prod's live files against prod's **own** pre-hotfix `.bak` backups, so they apply to prod's
backend version, not to this branch. The full current prod versions of all nine files are
preserved at `s3://testlogon-apk-749211675678/prod_hotfix_files.tgz`.

## EARLIER hotfixes baked into the `.bak` baselines (documented, in the S3 full-file bundle)

These were applied **before** the oldest `.bak` snapshot, so they are part of every `.bak`
baseline and therefore do **not** appear in the diffs above. They are present in the full prod
files (S3 bundle):

- `push.py` / `messaging.py`: FCM push permission gate + data-contract for notification taps.
- `messaging.py`: `/events/poll` polling endpoint + `message:new` payload flatten + realtime
  `send_message_push` fan-out trigger.
- `filemanager` service/router: `mkdir -p` parent-folder creation, dev-mode S3 metadata skip,
  server-side de-dup of folder keys, entitlement/once-media-grant bypass for normal files.
- `.env.local`: `CATALOG_INTERNAL_API_PACKAGE_ENABLED=false` (config, not code).

## To redeploy prod without losing these

Apply these patches (or re-do the documented changes) onto prod's real source branch, then
redeploy. Do **not** `git apply` them onto `android-impl` — the base does not match.
Full reference of every change also lives in the assistant memory file
`messaging-push-realtime-fixes.md`.
